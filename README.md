# Haircut

Ứng dụng Flutter quản lý khách hàng cho tiệm cắt tóc.

## Tính năng chính
- Quản lý khách hàng
- Ghi số điện thoại, ảnh, lịch sử cắt tóc
- Theo dõi khách follow / khách quen
- Thống kê doanh thu theo tháng
- Dữ liệu mẫu sẵn có để test nhanh
- Sẵn sàng tích hợp Firebase sau này

## Cài đặt
```bash
flutter pub get
flutter run
```

## Ghi chú
MVP này đang ở mức demo và có thể mở rộng theo nhu cầu thực tế.
